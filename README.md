## Overview

**React Playground** is a sandbox project designed for experimenting with React and modern web development ideas.

### Key Features

- ⚡ **Vite + React 19**: Ultra-fast dev server with HMR.
- 🛡️ **TypeScript**: Strict type checking for reliable code.
- 🎨 **ESLint & Prettier**: Enforced coding style and formatting.
- 📦 **Husky & Commitlint**: Git hooks for conventional and consistent commit messages.
